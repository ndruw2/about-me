# antislop audit 001 (2026-10-09)

Target: indrabayu.my.id (`index.html`, `styles.css`, `script.js`, `404.html`) at commit `8793ee2`.
Ruleset: miqdadbadjuber/anti-slop `antislop.md` (R-01 to R-38). Mode: AFTER.
Direction source: README design tokens (navy + cool brand blue, amber accent). No `DESIGN.md`.

Priority follows the rule tier: Hard Gate = HIGH, Purpose-Gate = MEDIUM, Quality Locks = LOW.

## HIGH

1. **R-03, mobile has no navigation.** `styles.css:425` hides `.nav__links` at 760px and below, and no menu button replaces it. On a phone, the only control in the navbar is the theme toggle.
2. **R-17 / R-38, invented language percentages.** `index.html:166-174` draws bars at 100% / 82% / 28%. Those numbers have no source. The text levels ("Native", "Professional working", "Beginner") already say it.
3. **R-02, em dash in copy.** `index.html:13` has an em dash in `og:description`, which is the text LinkedIn and WhatsApp show when the link is shared.

## MEDIUM

4. **R-04, Lucide icon set chosen for its library look.** `script.js:5-45` holds 16 Lucide glyphs, several of them generic (`layout-grid`, `cpu`, `infinity`, `share-2`, `globe`). The README confirms they were chosen as "Lucide". The labels carry the meaning on their own.
5. **R-14, 16 identical competency cards.** `script.js:48-65` plus `styles.css:250-280`: same size, icon tile, padding, and hover for all 16. Nothing shows which areas are core and which are supporting.
6. **R-13 / R-12, glow + lift on every component.** Hover glow and translate/scale on stat cards, skill cards, badges, both buttons, education cards, contact items, the theme toggle, and job dots (`styles.css:127-403`). That is well past the 1-2 element cap.
7. **R-01, radial orbs + blue-to-indigo gradient text.** `styles.css:138-144` draws two radial glows behind the hero. `styles.css:154-158` puts a sky-to-indigo gradient on the job title. Neither has a written hierarchy reason.
8. **R-19, template motion everywhere.** Every block uses fade-up `.reveal` (`styles.css:412-417`), stats count up from 0 (`script.js:319-355`), and every card scales on hover. The stated purpose is "micro-interactions", which is decoration, not UX.
9. **R-06, uppercase wide-tracked labels.** Hero eyebrow, `01 / PROFILE` kickers, stack group labels, job periods, and contact labels are all uppercase with 0.04-0.1em tracking (`styles.css:146,228,285,340,404`).
10. **R-09, capsule + dot on every tech badge.** `styles.css:295-316`: pill + border + dot + hover glow on all 34 badges. The labels are real; the decoration is not needed.
11. **R-08, arrow inside CTA text.** "Open to Saudi Arabia roles → Let's talk" (`index.html:59,195`) reads as two CTAs glued together with an arrow.

## LOW

12. **R-05, uniform section rhythm.** Every section is kicker + title + amber underline + note + grid, and the only variation is alternating backgrounds (`section--alt`).
13. **R-29 / one-accent lever, amber is everywhere.** Amber shows up on the CTA, nav underline, every title underline, section dividers, kickers, badge dots, timeline line, dots, period pills, icon tiles, list bullets, and language bars. It no longer marks anything.
14. **C-3, repeated copy.** "Twelve years building consumer-tech platforms that scale to millions and stay secure under real attack" appears in the hero lede, the summary, and the OG description. The Saudi CTA appears twice and the contact lead restates the summary highlight. Kickers repeat the titles ("02 / Core competencies" above "Core competencies").
15. **C-4, theme flash on load.** The theme is applied in a deferred script (`script.js:227-239`), so light-mode visitors see the dark page first.
